# 镜头与剪辑标注助手

把看片变成可迁移的画面表达训练。默认分析用户给来的完整视频，制作中文标注 MP4；不要停在文字报告或截图。

## 目标与边界

- 同时解释镜头内部的景别、角度、动作和运镜，以及镜头间的切点、转场和衔接。
- 用“看到什么 → 叫什么 → 给 AI 怎么说／真实素材怎么剪”解释，以中文为主。
- 分开生成指令和剪辑指令。不要用内容策划、流量钩子或剧情摘要替代技术分析。
- 完成后默认请求本机播放器打开，无须再次询问。只能报告操作系统是否接受请求，不能声称用户已看见窗口。
- 脚本处理媒体；模型实际查看画面并填分析。没有查看能力时停止语义分析，不虚构标签。

## 1. 确认输入和执行位置

阅读项目说明和适用的 AGENTS.md。定位用户指定视频；上传文件仅在聊天宿主可见时，先用宿主文件工具取得本地路径。

确认命令运行在 Workbuddy 电脑还是云端。云端打开文件不等于打开用户电脑。远程工具拒绝路径或命令时遵守边界，不换工具绕过。

下文 `<skill>` 是本 SKILL.md 所在目录，其他占位符替换为实际绝对路径。Windows 可以使用 `py -3`。

```bash
python3 "<skill>/scripts/video_notes.py" doctor
python3 "<skill>/scripts/video_notes.py" prepare --input "<视频>" --out "<新的工作目录>"
```

需要 Python 3.10+、Pillow、ffmpeg、ffprobe。先用已有依赖，缺失时按宿主允许的方式安装。参阅 [运行与 Workbuddy 适配](references/runtime.md)。

## 2. 取样并查看

读取 manifest.json，打开全部 contact-sheets，再逐镜头查看连续帧。candidate_cuts 只是候选：闪光、字幕和运动可能误报，叠化或遮挡可能漏报。实际确认、合并或补充边界，不能直接当成镜头表。

有运动的镜头至少比较前、中、后三个时刻；每个切点都查看前后连续画面。快速转场或不确定运动使用加密取样：

```bash
python3 "<skill>/scripts/video_notes.py" window --input "<视频>" --out "<新的窗口目录>" --start 4.2 --end 5.6 --fps 12
```

时间标签是请求取样时间，可能相差一帧。精确剪切结合短片播放或逐帧核对。不要用一张截图推断运动，也不要用每秒一帧推断快速转场。

能试听时检查原声和全部接点；无法试听则把音频状态标为 unavailable，不猜声音桥、卡点、口型和声画同步。无音轨标为 no-audio。

## 3. 建立镜头表和接点表

阅读 [标注格式](references/annotation-format.md)、[术语与判断](references/visual-language.md)。必要时核对 [原始资料](references/sources.md)。从 analysis.template.json 创建 analysis.json。

每镜记录实际观察、景别和角度、主体动作、运镜、必要的景深效果、证据、置信度、中文生成描述和真实素材剪辑建议。

- 区分主体移动、相机移动、变焦和后期裁切放大。人物变大不独立证明推进。
- 在 AI 画面中描述“呈现出的效果”。不足以区分时保留未知和必要的替代解释。
- 不猜真实焦距/光圈、模型品牌、原始提示词、作者心理和软件名称。
- 图生视频重点写运动和变化；文生视频补充主体、场景、构图。不擅自调用付费生成。

为全部相邻镜头建立接点，不遗漏硬切。记录前镜结束状态、后镜开始状态、切点或转场区间、动作/方向/主体位置/构图/光线/声音如何对应、证据、置信度、生成素材的起止条件和真实素材剪辑步骤。

混合效果分项描述；不要把 AI 连续变形直接称为叠化。剪辑指令说明在哪里截、接哪个动作阶段、是否需要遮挡/叠化/速度调整。生成指令说明素材自身动作与起止状态，不把跨片剪辑塞入单个生成描述。

只有检查了全部镜头和接点，才设置 review.visual 为 complete。未知条目可以保留，但必须显示对应置信度；空模板不能交付。

## 4. 校验、渲染与打开

```bash
python3 "<skill>/scripts/video_notes.py" validate --input "<视频>" --analysis "<工作目录>/analysis.json"
python3 "<skill>/scripts/video_notes.py" render --input "<视频>" --analysis "<工作目录>/analysis.json" --out "<新的成片目录>" --open
```

脚本校验源指纹、时长、镜头覆盖、全部相邻接点、证据图片和检查状态；不替代语义审查。

原画面下方独立显示中文讲解区，保留原声与原速时间线。镜头内显示观察、术语、生成描述；接点附近显示衔接方法与剪辑指令。完整内容写入《镜头与剪辑说明.md》。短镜头可暂停、回退阅读，不擅自拉长原片。

打开输出代表帧检查字形、换行和画面完整性；检查接点前后、整片解码、输出时长与音轨。自带字体缺字时报错，传入 --font 指定完整中文字体，不交付方框字。

只有在本机图形环境接受打开请求时，报告“已请求本机播放器打开”。云端或权限不足时，通过宿主文件能力交付，报告真实限制，不把云端路径当本机路径。

最终简要报告镜头/接点数量、标注视频与说明位置、未知判断、打开结果。用户没有给视频时，报告技能就绪并给一句调用示例。慢放回放和语音讲解仅在用户要求时另做，不冒充首版已实现。
