# 术语与判断

## 镜头内部

| 观察 | 描述 | 检查 |
| --- | --- | --- |
| 人物较小，环境占主要范围 | 远景 | 主体与环境比例 |
| 人物全身基本完整 | 全景 | 实际截取范围 |
| 常见为腰部以上 | 中景 | 教材边界略有差别，补实际取景范围 |
| 常见为胸肩以上 | 近景 | 补实际取景范围 |
| 面部或局部占主要画面 | 特写 | 手、产品和菜品也可特写 |
| 机位基本固定而转向 | 摇摄 | 区分机位整体平移 |
| 相机整体靠近/远离 | 推进/拉远 | 检查透视与前后景相对运动 |
| 相机整体向左右移动 | 横移 | 不同距离物体的相对位移 |
| 相机跟随主体 | 跟拍 | 同时描述方向、距离和主体位置 |
| 围绕主体走弧线 | 环绕/弧线移动 | 能否持续看到主体不同侧面 |
| 主体变大但透视证据不足 | 变焦/裁切放大/推进无法区分 | 不写死物理来源 |
| 主体清晰，背景明显模糊 | 浅景深效果 | 排除运动模糊和低清晰度 |
| 清晰区域在物体间转移 | 焦点转移效果 | 检查连续变化，不猜距离 |

分开主体动作和运镜；组合运动说明先后或同时关系，避免互相冲突的指令。

## 镜头之间

| 方式 | 证据 | 制作方法 |
| --- | --- | --- |
| 直接切换/硬切 | 无可见混合区间 | 选定动作或信息切点直接接入 |
| 同一动作衔接 | 前镜动作在后镜继续 | 对齐动作阶段，避免重复或跳过 |
| 构图/形状呼应 | 位置、形状或布局相似 | 对齐裁切与主体位置 |
| 遮挡衔接 | 物体经过并遮满画面 | 充分遮挡时切，核对两边方向 |
| 快速甩动衔接 | 切点两侧快速运动与模糊 | 对齐方向、速度、模糊阶段 |
| 叠化 | 一段时间同时可见两画面 | 记录重叠区间和混合过程 |
| 淡入/淡出 | 逐渐进入或离开黑/白 | 标出变化区间与目标颜色 |
| 连续变形 | 物体/场景持续改变形状身份 | 来源不明时不判定剪辑或 AI |
| 声音提前进入 | 下一镜声音先出现 | 实际试听后标注，常称 J-cut |
| 声音继续延伸 | 上一镜声音延续到下一镜 | 实际试听后标注，常称 L-cut |

检查动作阶段、左右方向、位置、大小、色温和亮度；这些是可用衔接条件，不要求全部相同。故意跳跃或反差也可能成立，作者意图只能作为解释。

## 证据与提示词

high：连续画面直接支持；medium：支持但存在其他实现；low：仅部分线索；unknown：无法区分。置信度跟随对应注释显示，不给未标定的精确概率。

生成描述：主体/场景（需要时）→取景与角度→主体动作→运镜→速度→必要起止状态。不要用“电影感、高级、8K”代替具体动作。

剪辑描述：前素材截取位置→后素材入点→动作/方向/构图对应→必要声画处理。时间必须来自实际检查，不能用示例时间冒充原片时间。
